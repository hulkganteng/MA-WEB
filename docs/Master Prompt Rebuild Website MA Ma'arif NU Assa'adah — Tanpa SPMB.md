# 50. SECURITY AUDIT WEBSITE LAMA

Sebelum migrasi konten, audit website lama.

Karena ditemukan indikasi konten/link spam tidak relevan pada website lama, anggap seluruh source lama sebagai:

**UNTRUSTED SOURCE**

Lakukan:

1. Backup source code.
2. Backup database.
3. Scan malware.
4. Cari file PHP asing.
5. Cari file yang baru dimodifikasi secara mencurigakan.
6. Periksa `.htaccess`.
7. Periksa cron jobs.
8. Periksa user admin.
9. Periksa database.
10. Cari external links mencurigakan.
11. Cari iframe asing.
12. Cari JavaScript injection.
13. Cari PHP obfuscation.
14. Cari penggunaan `eval`.
15. Cari penggunaan `base64_decode` mencurigakan.
16. Periksa upload directory.
17. Periksa DNS.
18. Periksa FTP/SFTP account.
19. Rotasi credential.
20. Jangan menyalin seluruh `public_html` ke website baru.
